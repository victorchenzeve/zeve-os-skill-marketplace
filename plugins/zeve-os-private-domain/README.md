组合人群分层、活动策划、对话复盘、生命周期和留存实验能力。

## 包含的 Skill

- `private-domain-audience-segmenter`
- `private-domain-campaign-planner`
- `private-domain-conversation-reviewer`

## 使用边界

插件只分析、规划、审查和起草。任何外部写入、发布、客户触达或付费动作都需要用户针对具体动作授权。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
