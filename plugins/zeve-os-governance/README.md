# 泽玮 OS Skill 治理

组合资产纳管、来源许可、重复关系、成熟度、批次审查、工作区诊断和发布审计能力。

## 包含的 Skill

- `marketplace-asset-curator`
- `skill-provenance-reviewer`
- `skill-duplicate-adjudicator`
- `skill-maturity-evidence-reviewer`
- `zeve-skill-release-auditor`
- `skill-wave-reviewer`
- `zeve-codex-workspace-doctor`

## 使用边界

插件默认只分析、规划、审查和起草。任何外部写入、发布、客户触达、账户访问、安装或付费动作都需要处于用户明确授权范围。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
