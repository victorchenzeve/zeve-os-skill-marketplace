# 泽玮 OS 研究工作台

组合问题界定、来源规划、来源路由、证据综合和主张核验能力。

## 包含的 Skill

- `research-question-framer`
- `research-source-planner`
- `research-evidence-synthesizer`
- `research-claim-verifier`
- `research-source-router`

## 使用边界

插件只分析、规划、审查和起草；视频处理仅在用户指定本地输入与输出后执行。任何外部写入、发布、客户触达、账户访问或付费动作都需要用户针对具体动作授权。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
