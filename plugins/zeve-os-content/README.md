# 泽玮 OS 内容运营

组合内容策略、角度、生产排期、质量审查和再利用规划能力。

## 包含的 Skill

- `content-strategy-brief`
- `content-angle-generator`
- `content-production-planner`
- `content-quality-reviewer`
- `content-repurpose-planner`

## 使用边界

插件只分析、规划、审查和起草。任何外部写入、发布、客户触达或付费动作都需要用户针对具体动作授权。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
