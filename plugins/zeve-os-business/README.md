# 泽玮 OS 业务决策

组合机会界定、方案设计、单位经济性、实验规划和决策备忘录能力。

## 包含的 Skill

- `business-opportunity-framer`
- `business-offer-designer`
- `business-unit-economics-reviewer`
- `business-experiment-planner`
- `business-decision-memo`

## 使用边界

插件只分析、计算、规划和起草。任何外部写入、报价、签约、客户触达、资金或发布动作都需要用户针对具体动作授权。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
