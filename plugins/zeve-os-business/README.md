# 泽玮 OS 业务决策

组合机会界定、方案设计、单位经济性、实验规划、个人 AI 工作流和决策备忘录能力。

## 包含的 Skill

- `business-opportunity-framer`
- `business-offer-designer`
- `business-unit-economics-reviewer`
- `business-experiment-planner`
- `business-decision-memo`
- `zeve-personal-ai-workflow-designer`

## 使用边界

插件只分析、规划、审查和起草；视频处理仅在用户指定本地输入与输出后执行。任何外部写入、发布、客户触达、账户访问或付费动作都需要用户针对具体动作授权。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
