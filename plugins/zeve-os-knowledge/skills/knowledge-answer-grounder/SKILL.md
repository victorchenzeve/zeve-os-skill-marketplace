# 知识回答溯源

## 触发条件

当用户需要“仅依据给定知识记录生成逐主张溯源、处理冲突并明确不确定性的回答”时使用。若输入来源、权限或任务目标不满足边界要求，先说明缺口并采用安全的降级输出。

## 输入

需要问题、可使用的知识记录、来源定位和适用时间。可选提供受众、回答长度和术语表。

## 执行步骤

1. 拆解问题中的事实、解释和行动建议。
2. 检索与每个子问题直接相关且仍适用的知识记录。
3. 建立主张到来源的映射，识别冲突、过期和证据空白。
4. 只用足够证据支持的内容组织回答，并在主张附近标注来源。
5. 明确未回答部分、可信边界和需要补充的资料。

## 输出

输出简明回答、逐主张来源、冲突说明、可信度和未解决问题。

## 权限与边界

不使用未提供或未授权的私有知识，不把模型记忆冒充来源，不隐藏相互冲突的记录。

## 失败处理

没有支持证据时明确回答“资料不足”；来源冲突且无法判优时并列呈现。

## 验证方法

使用成功、缺失输入和边界风险三类合成用例验证；逐项检查输出结构、事实边界和失败降级。证据保存在 `evals/knowledge-answer-grounder/`。
