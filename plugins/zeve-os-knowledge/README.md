# 泽玮 OS 知识治理

组合来源摄取、分类设计、回答溯源、时效审计和可追溯知识库构建能力。

## 包含的 Skill

- `knowledge-source-ingestor`
- `knowledge-taxonomy-designer`
- `knowledge-answer-grounder`
- `knowledge-freshness-auditor`
- `zeve-knowledge-base-builder`

## 使用边界

插件只分析、规划、审查和起草；视频处理仅在用户指定本地输入与输出后执行。任何外部写入、发布、客户触达、账户访问或付费动作都需要用户针对具体动作授权。插件内 Skill 为自动生成的发行镜像，正式源位于仓库 `skills/`。
