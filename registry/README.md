# 正式注册表

| 文件 | 记录对象 |
| --- | --- |
| `skills.yaml` | 已按仓库标准纳管的技能 |
| `plugins.yaml` | 内部插件包及其技能成员 |
| `agents.yaml` | 代理说明及其技能成员 |
| `dependencies.yaml` | 正式资产之间的显式依赖边 |

四份注册表使用 YAML 1.2 的 JSON 子集，结构版本为 `2.0.0`。格式定义见 `schemas/`，运行 `npm run validate` 校验。2.0 结构要求每个正式 Skill、插件和代理登记许可证、来源分类、所有者、复核日期、评估状态和证据路径。

当前注册 29 个 Skill、6 个插件、6 个代理和 26 条显式依赖。插件及代理成员还会作为隐式依赖参与循环检查。

Inventory 与 Registry 相互独立。已安装技能不会因为出现在盘点结果中而自动注册；第三方资产仍需完成来源、许可证、结构和评估审查。
