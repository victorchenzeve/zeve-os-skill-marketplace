# 版本策略

仓库和各资产独立使用 `MAJOR.MINOR.PATCH` 三段非负整数版本；当前注册格式暂不支持预发布或构建后缀。

- MAJOR：输入、输出、权限边界或调用方式发生不兼容变化。
- MINOR：增加兼容能力或可选参数。
- PATCH：修复问题、修正文档且不改变接口。

`schemaVersion` 是注册格式版本，当前为 `1.0.0`。格式升级须同时修改 Schema、校验器、测试及迁移说明。资产版本由人工审阅确认；校验器只检查格式，不推断变更影响。

行为变化写入 CHANGELOG.md。删除或替换稳定资产前先弃用，说明迁移路径；发布标签和远程发布另按用户授权执行。

## 仓库发行

仓库发行版本与 Git Tag 使用 `vMAJOR.MINOR.PATCH` 对齐。发行前生成 npm tarball、SHA-256 校验文件并完成隔离安装；Tag 推送触发 Release 工作流。资产版本独立于仓库版本，单个资产没有行为变化时不随仓库版本被动升级。
