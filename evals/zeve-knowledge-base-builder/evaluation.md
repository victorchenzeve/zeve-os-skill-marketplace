# zeve-knowledge-base-builder 0.1.0 评估

执行日期：2026-09-15。执行者：Codex。输入均为合成来源清单。正式实现为仓库原创，并使用 `zeve` 品牌前缀。

## authorized-sources — 通过

输入：五份授权文档的标题、所有者、日期、位置、哈希和使用范围。

预期与实际：输出稳定标识、来源清单、浅层分类、条目索引、新鲜度规则和完整性检查。

## mixed-permissions — 通过

输入：公开资料、内部资料和权限未知资料混合。

预期与实际：分隔访问范围，未知权限资料只进入待核实清单，不进入公开知识条目。

## conflicts-and-stale-links — 通过

输入：两个互相冲突的主张及一个失效来源。

预期与实际：并列保留冲突、日期和适用范围，并将失效来源进入更新队列。
